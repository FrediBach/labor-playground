# Simulation engine and audio implementation notes

This prototype uses **eecircuit-engine 1.8.0**, pinned exactly in `package.json` and `package-lock.json`. Its installed WASM identifies itself as **ngspice 45.2**, built **2026-09-05 01:00:10 UTC**, with the KLU direct solver compiled in. The startup log reports SPARSE as the active solver. No custom circuit solver or prerecorded waveform fallback is used.

## Runtime boundary

The documented API is `new Simulation()`, `await start()`, `setNetList(netlist)`, and `await runSim()`. Inspection of the installed distribution confirmed that this API creates no Web Worker: the asynchronous Emscripten simulation runs in the caller's context. Therefore `src/lib/simulation.worker.ts` imports and initializes the entire engine inside a dedicated Vite module worker. The UI thread handles document compilation and rendering; the worker handles WASM initialization, the electrical solve, and extraction of the two probe channels. See the [upstream API](https://github.com/eelab-dev/EEcircuit-engine).

The npm package embeds the WASM binary and its model library in its ESM distribution, about 19 MB before bundling/compression. There is no runtime CDN, external model fetch, simulation service, or server API. Vite emits the worker as a static application asset. The package declares no runtime npm dependencies of its own. The application otherwise uses its existing React/Vite frontend stack; `@playwright/test` is a development dependency only.

The engine executes `source`, `destroy all`, `run`, and `write out.raw`. The wrapper exports only the current plot, so each production capture runs **a separate `.op` analysis followed by `.tran`** in the same worker. Both netlists come from the same circuit snapshot and use identical node/device names. Their results are published together under one revision only after both analyses succeed. Reference ground is exactly zero; unused or disconnected probe nodes remain unavailable. Channel traces, adaptive timestamps, exposed node voltages, measured device currents, compact part descriptors/diagnostics, and the operating point cross the worker boundary. Probe and recording vectors share their number arrays; no additional per-component waveform or per-frame state copies are retained.

The operating-point plot is validated as a single real row with finite node voltages and every component pin present. Its completion log must contain the matching new data-row count and raw-file write, and its plot name must be Operating Point. The transient separately needs its own Transient Analysis plot, matching completion log, and full requested time interval. A prior raw file cannot be accepted merely because the wrapper returned it after an unsuccessful run.

## DC operating point

The operating-point panel reads actual `.op` node voltages, independently of scope capture means and cursor values. For a square-wave RC input, `.op` uses the source's initial DC value even when the later waveform has a near-zero time-weighted mean. Every readout is hidden when its circuit revision becomes stale or invalid.

Resistor and switch currents are calculated from these solved DC voltage differences and their exact compiled resistance. Potentiometers report both CCW-to-wiper and wiper-to-CW currents using the same 1 Ω endpoint floor as the electrical model. Signal, Schottky, zener and LED currents come directly from explicit `.save @D_device[id]` vectors in the `.op` netlist; their nonlinear current is never inferred from an assumed forward voltage. Inductor current comes from `.save @L_device[i]`, including the voltage drop and dissipation of its 1 Ω winding resistance. Bipolar transistors save `@Q_device[ic]` and `@Q_device[ib]`; their power is `Vce × Ic + Vbe × Ib`. Negative PNP terminal currents retain their sign. Power is the sum of branch voltage times branch current, in watts. Positive current follows the displayed pin direction.

Ideal capacitors have zero steady DC current and zero DC dissipated power; this is labelled as an ideal-model result and does not describe charging current. Generic op-amp current and dissipation are unavailable because its behavioral voltage model has no supply-consumption model. Missing requested pin voltages or saved diode currents fail the measurement instead of producing a zero. Unused holes have no invented DC voltage.

## Capture behavior and limits

- The interface offers 100 ms, 500 ms, 1 s, 5 s, and 10 s recordings. Duration is part of the capture identity. The adaptive solver uses a duration-scaled baseline grid, at least 80 samples per connected oscillator period, tighter local truncation control for analog transitions, and an RC-dependent step bound for 555 timing thresholds. Disconnected OSC/EG sources are omitted; they do not dictate the step size of an unrelated circuit. See `performance.md` for the exact policy and measured results.
- Every request carries a revision. An edited document immediately makes older results stale, including while Auto update is off. Late results never replace the current document's capture.
- Edits are coalesced for 160 ms. There is one running request and at most one replaceable pending request.
- Initialization gets 30 seconds; the combined operating-point and transient job gets 8 seconds for 100 ms captures or 60 seconds for longer captures. On failure or timeout, the worker is terminated and the next Capture creates a new one. The circuit document is preserved.
- Results above 1,000,000 samples or 12,000,000 numeric electrical values, invalid timestamps/voltages, and recordings that do not cover the complete requested interval are rejected. The compiler rejects configurations whose minimum expected output already exceeds this budget; runtime checks also account for additional adaptive rows. These are output limits; the solver, raw parsing, and worker transport also need working memory. No samples are silently discarded.
- Each capture restarts from its defined operating point. Capacitor charge is not carried between captures or edits. There is no continuous physical timeline.
- Device, stimulus, and numerical simplifications are described by `PARTS`, the generated netlist, and `hardware-spec.md`. The library includes sixteen component kinds. The TL072-style dual op-amp uses explicit supplies, finite gain, output resistance, and output limiting; the potentiometer uses a 1 Ω endpoint floor.

The displayed scope data remains unprocessed electrical voltage. Whenever a capture is not current, the scope hides its previous traces and measurements. Listen is unavailable until a current capture succeeds, so new probe labels never describe older electrical results.

The worker distinguishes failed runs from a documented ngspice recovery sequence. Exact dynamic/true gmin-stepping failure warnings are accepted only when a later source-stepping-completed message exists and the current analysis has a validated, freshly completed result: one `.op` row or the full requested transient interval. Other failures, singular matrices, aborted runs, and incomplete recovery remain errors. A narrow 50 ms monitor also detects irreversible abort/write failures when the upstream wrapper otherwise leaves its result promise pending. This monitor does not reject intermediate gmin warnings; the independent main-thread watchdog remains responsible for terminating a blocked worker.

The recording inspector performs one binary search for a selected time, then interpolates adjacent solver rows across every exposed voltage and saved device current. Capacitor charging/discharging current comes from `@C_device[i]`, separately from its zero DC current. Resistor/potentiometer currents use the solved voltage differences; power is signed instantaneous branch voltage times current. Capacitor power may be negative while returning energy. Behavioral IC current/power remains unavailable. The recording playhead, part/wire inspector, and LED state all use this selected transient state; replay does not rerun the solver or preserve charge across separate captures.

Polarized capacitors are checked against the simultaneous voltages on both physical leads throughout the capture. A negative differential beyond −50 mV produces a part-specific reverse-bias warning with the maximum measured magnitude. Missing or malformed vectors for an explicitly requested capacitor check fail the capture rather than silently skipping the diagnostic. These checks do not alter the ideal capacitance or model damage, and they are displayed only for the current revision.

## Expanded discrete models

Inductance is editable from 1 µH to 10 H, initially 10 mH. A native SPICE inductor is in series with a fixed 1 Ω resistor, avoiding ideal-source/inductor DC loops and making winding dissipation explicit. It provides a DC return; capacitors do not. Each capture resets to the operating-point current. There is no magnetic saturation, core loss, mutual coupling, or thermal model.

The generic Schottky diode uses `Is=200 nA`, `N=1.05`, `Rs=0.2 Ω`, `Cjo=10 pF`, and `Eg=0.69 eV`. The generic zener uses `Is=1 pA`, `N=1`, `Rs=2 Ω`, `Cjo=50 pF`, and `IBV=1 mA`. Its editable `Part.value` is the nominal `BV` in volts (2.4–24 V, initially 5.1 V); each instance gets its own model. Actual terminal voltage varies with current and series resistance. Both diode variants preserve anode/cathode order and the visible cathode stripe.

NPN and PNP use complementary Gummel–Poon models with `Is=10 fA`, `Bf=100`, `Br=1`, `Vaf=100 V`, `Cje=10 pF`, `Cjc=4 pF`, `Tf=0.5 ns`, and `Tr=10 ns`. Their rigid adjacent three-pin package always orders collector, base, emitter, including when rotated. This is an educational footprint, not a manufacturer pinout. Bias changes reproduce cutoff, active gain, and saturation; breakdown, thermal effects, and damage are not modeled. The [ngspice manual](https://ngspice.sourceforge.io/docs/ngspice-manual.pdf) documents diode breakdown parameters, transistor terminal order, and saved device-current parameters used by these models.

## Timer and quad op-amp ICs

The **555 timer** uses the eight-pin sequence GND, TRIG, OUT, RESET, CTRL, THRESH, DISCH, VCC from the [TI NE555 datasheet](https://www.ti.com/lit/ds/symlink/ne555.pdf). Its original analog behavioral model has three 5 kΩ divider resistors, so an undriven CTRL is nominally 2/3 VCC and the trigger reference is half CTRL. A capacitor-backed latch retains state between trigger and threshold events; RESET below 0.7 V wins over TRIG, which wins over THRESH. The latch has a 100 ns time constant for numerical conditioning.

A deterministic **1 µs startup reset** makes the initial operating-point solve well-defined, including astable configurations. Therefore the 555's DC panel describes the reset state, not a settled oscillator or previous latch state. Every capture restarts this sequence. The model supports 4.5–16 V between its explicit VCC and GND pins, targets VCC−1.2 V high and 0.1 V low through 50 Ω, and uses a 10 Ω discharge path when low (1 GΩ off). It adds an approximate 3 mA supply load plus the real divider and sourced output-load current. Invalid supply voltage forces its output target to GND and disables discharge; known invalid or missing supplies block capture before simulation. These values describe the educational approximation, not guaranteed NE555 specifications. Temperature, component tolerance, supply spikes, damage, and exact output-current limits are omitted. IC current/power readouts are not exposed.

The **TL074-style quad op-amp** follows [TI's DIP-14 pin table and drawing, Table 4-6 / Figure 4-8](https://www.ti.com/lit/ds/symlink/tl074.pdf): positive supply pin 4, negative supply pin 11, and outputs A/B/C/D on 1/7/8/14. Four static sections use open-loop gain 10,000, 100 MΩ differential input resistance, 50 Ω output resistance, and clipping 1 V inside the connected rails. The lower finite gain, compared with the existing dual model’s 100,000, keeps cascaded sections convergent during heavy clipping; the tested gain-one/two utility differs by less than 3 mV from the ideal. Supply separation must exceed 2 V. All eight inputs need external DC returns; unused sections should be grounded followers. Bandwidth, slew rate, input common-mode limits, bias currents, noise, and supply consumption are omitted. It is not a manufacturer-calibrated TL074 model.

Both packages straddle the virtual trench, preserve numbered pin order through a 180° rotation, and validate every occupied hole on placement/import. The DIP-14 spans seven columns. The quad expands to 12 devices / 4 internal nodes and the 555 to 9 / 3. Later CMOS parts exceed the former 23-device / 4-node per-part estimate; that estimate is superseded by the compiler’s actual expansion checks: 1 MB, 1,000 devices and 300 internal nodes, alongside the 30-part, sample and worker-time limits.

Three editable lessons exercise these models: **555 clock oscillator** (~480 Hz with two 10 kΩ resistors and 100 nF), **555 trigger-to-pulse** (falling edge at 51 ms produces ~11 ms with 100 kΩ and 100 nF), and **TL074 buffered signal splitter** (all four sections produce positive/inverted buffered outputs). The timer tests use real ngspice to verify period/duty cycle, RC edits, CTRL loading, latch/RESET priority, monostable duration, supply-relative behavior, and finite output drive. IC integration tests check the complete compiler/capture pipeline, packages, supply diagnostics, and all four amplifier sections.

## Scope measurements

The expanded Measurements panel reports min/max, peak-to-peak, and the trapezoidal time integral divided by duration; adaptive rows are never treated as equally spaced. Cursor readings linearly interpolate actual timestamps and do not extrapolate. A/B positions remain in milliseconds across captures, with Δt and per-channel ΔV. The differential meter subtracts CH2 from CH1 at either cursor or uses the time-weighted capture mean. These are measurements of the transient data, not a separate `.op` run.

Frequency requires at least three complete periods with stable rising crossings and a repeating cycle shape, checking the settled end of the capture. DC, step stimuli, insufficient cycles, and irregular traces report unavailable. Input-step examples open at 10 ms/div to show the 1 ms rising edge and 51 ms falling edge together. Current channel data disappears when a capture becomes stale or invalid.

The optional scope trigger frames the current capture without rerunning simulation or changing the circuit history. CH1 or CH2 can trigger on the first confirmed rising or falling crossing of an adjustable voltage level, interpolated between actual timestamps. Confirmation requires traversing a hysteresis band of ±1% of the signal span, with a 1 mV minimum on each side. The view aims for 10% pre-trigger time and clamps to the available capture interval without extrapolation; when no crossing qualifies, it explicitly reports “No crossing found” and shows the capture start. Axis labels, hover readings, and A/B cursors always use absolute capture time, so framing does not change existing cursor measurements.

## TL072 naming and LM13700 dual OTA

The existing dual amplifier is now named **TL072-style dual op-amp**. Its [TL072 DIP-8 pinout](https://www.ti.com/lit/ds/symlink/tl072.pdf), gain of 100,000, clipping, input/output resistance, and supply validation are unchanged. Saved projects retain the `opamp` kind. The name describes the pin-compatible educational approximation, not manufacturer-level bandwidth, slew rate, common-mode range, noise, or bias behavior.

The **LM13700-style dual OTA** follows [TI's 16-pin package and operating principles](https://www.ti.com/lit/ds/symlink/lm13700.pdf). It uses two independent current-output amplifiers, with IABC A/B on pins 1/16, diode-bias inputs on 2/15, positive inputs on 3/14, negative inputs on 4/13, and outputs on 5/12. V− is pin 6 and V+ pin 11. Buffer input/output A is 7/8 and B is 10/9. The package spans eight columns and supports both trench orientations.

The original model in `src/lib/lm13700.ts` measures bias current through a two-junction diode equivalent into V−. Each OTA produces `IABC × tanh(Vdiff / 52 mV)`, with effective bias limited to 2 mA and differential input resistance approximately `13 / IABC` ohms. This gives small-signal transconductance about `19.23 × IABC` and peak output current about IABC. Output current is sourced from V+ or sunk into V−, rolls off within 0.8–1 V of the relevant rail, and has 100 MΩ leakage resistance to each rail. The supported total supply span is 9.5–32 V; known invalid, missing, or reversed supplies block capture. Unsupported dynamic spans disable OTA current, while passive junctions remain present. Supply consumption is approximate (`0.6 mA + 2 × summed bias current`, plus signal/load currents), so chip current and power are not exposed as calibrated measurements.

Two real diodes per half connect the diode-bias pin to the signal inputs. With external current feeds and input resistors they reduce distortion; they may also be left open. Both signal inputs still need external DC returns. Bias pins must be fed through a resistor, left open, or connected to V− for an unused section. Direct connections from IABC to a higher fixed supply are rejected. A diode-bias pin directly forward-biased by a known supply/input voltage is also rejected; feed it through a resistor. Each buffer is a separate Darlington transistor pair: it sources current, drops roughly two junction voltages, and requires an external pull-down resistor or current sink to V−. Unused buffers may remain open. A connected or probed buffer output without an external pull-down path raises a warning; a pull-up to V+ does not qualify. The model does not enforce the physical buffer's current rating or predict damage.

The **LM13700 voltage-controlled amplifier** example attenuates audio to about 5 mV, uses a 100 kΩ CV-to-IABC resistor, and converts output current to voltage through a 100 kΩ load. CV −5/0/+5 V gives approximately 0.6/1.1/1.6 V output peaks from 2.5 V input peaks. Zero CV still supplies bias relative to the negative rail; the example explicitly does not claim a zero-volt mute. The second OTA is disabled, with grounded inputs; optional diode and buffer outputs are unused. These parameters teach OTA gain control, not an exact production VCA. Bandwidth, slew rate, temperature variation, noise, offsets, mismatch, and damage are omitted. `tests/lm13700.test.ts` exercises both halves, current scaling and saturation, output compliance, diodes, buffers, optional pins, and supply references; `tests/lm13700-example.test.ts` validates the editable VCA and its CV/load changes with the actual engine.

## Audio monitor

`playCapture()` creates/resumes an `AudioContext` only after the explicit Listen action. Its third argument accepts the original numeric volume or `{ mode: 'once' | 'loop', volume, onEnded }`; one-shot remains the default. `stopAllAudio()` invalidates playback awaiting a suspended context and fades active playback out over 5 ms. Natural completion, explicit stop, cancellation, and failures each deliver `onEnded` once. The simulation hook mutes after document edits, Reset, and failed simulations; new captures never automatically restart listening.

`analyzeAudioLoop()` derives eligibility from the selected channel's actual capture, independently of the oscillator or envelope settings. It requires 3–8 complete cycles at matching rising crossings near the settled end, with periods within 1%, repeating phase shapes, and consistent cycle extrema. Shape checks include every recorded sample in phase-bin extrema, so narrow changing defects cannot hide between phase samples. The remaining partial cycle must agree too. DC, isolated steps, decaying or changing envelopes, irregular waveforms, insufficient cycles, and poorly sampled signals remain one-shot only. This is a conservative finite-capture stability check; it cannot prove that a circuit will remain periodic indefinitely.

Adaptive timestamps are interpolated onto a grid at four times the device's sample rate. A normalized 97-tap Hann-windowed sinc filter limits listening bandwidth to at most 10 kHz before decimation. Loop resampling uses only the verified crossing-to-crossing region, with circular filter taps and a whole PCM frame count; the source playback rate restores the exact measured duration. There is no arbitrary 100 ms wrap, crossfade, or per-cycle fade. DC removal and conservative peak scaling affect only monitor audio. PCM has a fixed 0.35 ceiling; `setMonitorVolume()` applies a live 0–0.35 level through a GainNode with 5 ms ramps, without restarting playback. One-shot PCM retains endpoint fades, and sustained playback fades only at start/stop.

The monitor is a bounded preview, not a calibrated audio interface. It accepts ordered finite captures up to 1 s / 100,000 samples, device sample rates of 8–192 kHz, and voltages within ±10¹² V to prevent numerical overflow. Loop fundamentals above the device's preview bandwidth are rejected. Longer recordings can still be inspected and replayed visually; audio retains its separate preview bounds. A validated periodic subset can sustain until explicitly muted. `tests/audio-loop.test.ts` covers adaptive timing, analytical RC startup, square/clipped signals, narrow irregular defects, seam continuity, exact pitch, alias attenuation, level limits, live volume, suspended-context cancellation, replacement, and end-state cleanup.

- Nonlinear limiting with opposing generic signal diodes.
- Bounded LED forward voltage and the documented open/closed switch resistance.
- All seventeen editable analog example documents, including attenuation, AC coupling, edge shaping, envelope following, mixing, attenuversion, and two-pole filtering with meaningful parameter changes.
- Probe extraction, adaptive resampling, DC removal, fade endpoints, and above-band attenuation.
- Latest-request coalescing and termination/recreation of a stuck worker using a controlled worker fixture.

`tests/expanded-components.test.ts` checks all five added kinds against the installed ngspice engine: RL step response and winding loss, lower Schottky forward voltage and reverse leakage, editable zener breakdown and forward conduction, and complementary BJT cutoff, active gain, saturation, signed terminal currents, and power. Schema ranges, rigid transistor footprints, DC connectivity, independent zener models, and SPICE-safe IDs are also covered.

Invalid-row, missing-vector, stale-raw-file, explicit recovery, and pending-after-abort fixtures verify that a failed DC analysis cannot produce a successful combined capture.

`tests/e2e/simulation.spec.ts` additionally checks the React hook with a controlled browser worker: equivalent-document replacements during a manual capture, rejection of late results after edits, error visibility across Auto update toggles, and reset after a cancelled capture. These fixtures live outside `src` and are excluded from the production bundle.

The initial local Node smoke run initialized in about 272 ms and completed the 10,008-point divider capture in about 51 ms after initialization. These are observations from this development environment, not cross-browser performance guarantees. Native ngspice is not installed in this workspace, so comparison with a separate native executable has not been performed. Browser integration is checked separately by the Playwright suite.

The combined DC/transient divider pipeline was also timed locally after initialization: the first DC run took 15.8 ms and the full pair 68.2 ms; four warmed runs spent 0.7–1.0 ms on DC and 37.6–43.6 ms on the pair. This measures the installed WASM engine in Node, not browser startup or rendering, and is not a performance guarantee for more complex circuits.

## Bounded custom characteristics (2026-10-02)

`tests/custom-components.test.ts` exercises the pinned engine through `runCircuitCapture`, including separate `.op` and transient analyses, `extractRecording` and `sampleRecording`. Resistors use a zero-volt series sensor and behavioral voltage source `I × R(abs(I))`; capacitors use a zero-volt sensor and charge-defined capacitor with a generated piecewise quadratic integral. Nested ternary expressions implement local polynomials and constant endpoint extension without global hinge-sum cancellation. The capacitor expression references its actual terminal voltage (`v(internal, b)`), not a bare `v` parameter. Names/descriptions never become netlist identifiers or expressions.

Fixtures cover increasing and admissibly decreasing resistance, signs, zero, exact knots, endpoint extension, ideal-model equivalence, signed charge and energy integrals, nonzero initial DC bias, reversed terminals, shorted terminals, automation recompilation, limit values and narrow segments. The 2 ms triangle fixture compares trapezoidal measured current/power integrals to analytic ΔQ/ΔE at every sample: tolerances 100 nC and 500 nJ, respectively. Resistor transient law residual tolerance is 1 mV; DC is 200 µV. These tolerances include the solver's existing `reltol=0.001` and integration around corners.

One local Node run of a 30-part mixed R/C circuit, sharing two 64-point definitions, generated 335,352 netlist bytes. At 20 Hz, a 100 ms capture used 1,044 samples and ~421 ms; a 10 s capture used 18,454 samples and ~7.2 s. These are measurements on this development machine, not performance guarantees. Faster signals and difficult circuit combinations can still hit the unchanged worker deadlines or the 1,000,000-sample / 12,000,000-value limits. The compiler caps netlists at 1 MB / 1,000 devices / 300 internal nodes; each custom part adds two devices and one internal node (less than the existing maximum IC expansion per part).

Accepted tables have 2–64 knots and bounds of 0–1 A / −100–100 V, minimum widths of 1 µA / 1 mV, and maximum absolute slopes of 10⁹ Ω/A / 1 F/V. Existing R/C bounds remain 10 Ω–10 MΩ and 100 pF–10 mF. Positive differential resistance is checked analytically at both ends of every segment. Tested bounds limit expression growth; they do not promise convergence for every interconnected nonlinear circuit. An unsuccessful analysis remains an error, never a silent linear fallback.


## Classic synth designs and CD4069UB

The original educational [CD4069UB model](../src/lib/cd4069.ts) follows the [TI DIP-14 pinout](https://www.ti.com/lit/ds/symlink/cd4069ub.pdf): inverter input/output pairs 1/2, 3/4, 5/6, 9/8, 11/10, 13/12; VSS pin 7 and VDD pin 14. Each continuous transfer is `VSS + span/2 × (1 − tanh(40 × (Vin_relative/span − 0.5)))`, with midpoint gain −20. Output resistance is 500 Ω, output/input capacitances are 20/5 pF, and input leakage is 1 TΩ. There is no hysteresis or startup forcing. This supports self-bias and analog feedback, which the CD40106 Schmitt model cannot substitute for. The transfer curve and resistance are illustrative, not a manufacturer fit or a prediction of an original WASP’s distortion spectrum.

Drive is disabled outside a 3–18 V rail span; known incorrect or absent supplies block compilation, and inputs require visible external DC paths. All model voltages reference the connected VSS. Supply current, input protection, process variation, noise and thermal behavior are omitted. IC current/power remain unavailable through the existing package descriptor path. Expansion is 30 devices and six internal nodes per package; all existing compiler limits remain enforced. The additive `cd4069` kind uses ordinary schemas 1–4; existing documents and model behavior are unchanged. Older app builds that do not know this kind cannot import a project containing it.

[Seven example documents](../src/lib/synth-design-examples.ts) use ordinary placed parts and physical jumpers, generated by a private example-layout helper. Named connections exist only while authoring the examples; `resolveTopology` and the normal compiler remain authoritative. Board widths adapt to the examples, and schematic groups identify stages without changing electrical meaning.

- **SEM-inspired VCF:** an OTA state-variable loop with band-pass/low-pass outputs and an accessible high-pass summer. Two inverting integrators use 100 kΩ/1 kΩ input dividers, 10 nF capacitors and equal resistor-fed bias currents. Nominal `f0 = gm × divider / (2πC)`; `Q ≈ (R4 + R5)/(3R5)`. This demonstrates the [SEM state-variable architecture](https://downloads.arturia.net/products/sem-filter/manual/filter-sem_Manual_1_2_0_EN.pdf) using LM13700/TL074 models, without an exponential converter or original SEM component implementation.
- **Late MS-20-inspired low-pass:** follows [René Schmitz’s OTA/op-amp adaptation](https://www.schmitzbits.de/ms20.html). The incoming signal drives each OTA’s positive input; its buffered output returns to the negative input through a matching attenuator. Crucially, the first timing capacitor returns to the resonance amplifier output. That capacitive positive feedback reduces damping, with approximate `Q = 1/(2 − K)` for matched poles and resonance gain K. Opposing red LEDs limit feedback. This is not the early Korg-35 topology; the original exponential bias converter, high-pass section and exact limiter parts are omitted.
- **WASP-inspired VCF:** follows the CMOS-amplifier/OTA state-variable principle described in [the Haible/Schmitz WASP adaptation](https://www.schmitzbits.de/wasp.html). It uses an explicit self-biased inverter midpoint, AC input coupling, leaky OTA/CMOS integrators and band-pass damping feedback. The replacement LM13700 runs on +5/−12 V; the CMOS uses +5 V/GND. CV is the fixed +5 V supply, and R10/R14 tune bias together. Original distortion/output-switch circuitry and the CV converter are omitted. Outputs retain their approximately 2.5 V DC bias.
- **Triangle core:** an LM393 Schmitt comparator drives a TL072 integrator. The visible EG trigger breaks the noiseless DC equilibrium through R6; no solver state or hidden startup driver is added. The 10 MΩ feedback resistor provides a real DC return. Finite pull-up/sink behavior makes the two slopes slightly unequal.
- **Current-ramp saw core:** a PNP current source with a divider-set base charges C1 between the 555 thresholds. The 1 kΩ discharge resistor limits reset current and keeps latch-delay undershoot small. Unlike the existing resistor-charged astable, its charge segment is approximately linear. It is not a calibrated musical VCO.
- **Vactrol low-pass gate:** an LDR, shunt capacitor and load resistor change cutoff and gain together; a follower isolates the output load. This first-order example extends the existing optical audio gate and does not claim to reproduce a complete Buchla 292.
- **Asymmetric slew:** a diode selects a faster initial charging path; a permanent resistor completes charging and controls decay. The TL074 buffer uses the existing lower-gain approximation for robust transient convergence. Timing is exponential, not constant-slope.

[CD4069 regressions](../tests/cd4069.test.ts) cover every inverter, midpoint transfer, rail offsets, finite output loading, self-bias, disabled supply behavior, import/rotation and missing connections. [Design regressions](../tests/synth-designs.test.ts) use real ngspice DC/transient captures for responses, bias/resonance edits, oscillator startup and capacitor scaling, LPG brightness/decay and slew timing. [Browser coverage](../tests/e2e/examples.spec.ts) loads and captures all seven, inspects the new IC and schematic, and checks recovery. Existing schematic/KiCad tests also enumerate these new documents.
